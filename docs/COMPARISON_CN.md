## 主な利点

1. **セルフチェック + 繰り返し改善のループ** — 純粋な SKILL.md 方式の中で唯一、出力を自動で読み取って問題を修正し、複数ラウンドの作り込みに対応
2. **6 種類の図表プリセット** — ERD、UML クラス図、シーケンス図、アーキテクチャ図、ML/深層学習、フローチャートのそれぞれに、専用の形状、スタイル、レイアウト規範を用意
3. **ML/DL モデル図** — テンソル形状の注釈、レイヤー種別ごとの配色、エンコーダ/デコーダのスイムレーンなど、学術論文向けに設計
4. **マルチエージェント・ゼロ設定** — 必要なのは `skills/drawio-skill/` ディレクトリと draw.io デスクトップ版だけで、6 プラットフォーム横断で動作。MCP、Python、Node.js、ブラウザは不要
5. **プロフェッショナル品質のレイアウト** — グリッドに沿った座標、複雑度に応じた間隔、ルーティング用の通り道、ハブ中央配置戦略、アニメーション接続線
6. **ブラウザフォールバック** — デスクトップ CLI が使えないときは diagrams.net の URL を生成し、エクスポート後にデスクトップ版を自動で開いて編集に移行
