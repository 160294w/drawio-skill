## skill なしのネイティブエージェントとの比較

| 機能 | ネイティブエージェント | 本 skill |
|------|-----------|---------|
| draw.io XML 生成 | はい — LLM 自体がフォーマットを理解 | はい |
| エクスポート後のセルフチェック | いいえ | はい — PNG を読み取り 6 種の問題を自動修正 |
| イテレーティブフィードバックループ | いいえ — 手動で再質問が必要 | はい — 的を絞った編集、5 ラウンドの安全弁 |
| 能動的トリガー | いいえ — 明確に要求された時のみ | はい — 3+ コンポーネント時に作図を自動提案 |
| レイアウト規範 | なし — 毎回結果が一致しない | 複雑度別の階層スペーシング、ルーティングコリドー、hub 中央配置戦略 |
| グリッド整列 | いいえ | はい — すべての座標を 10px の倍数に整列 |
| 図表タイププリセット | いいえ | はい — 6 種のプリセット（ERD、UML、シーケンス図、アーキテクチャ図、ML/DL、フローチャート） |
| アニメーション接続線 | いいえ | はい — `flowAnimation=1` データフロー可視化 |
| ML/DL モデル図 | いいえ | はい — テンソル形状アノテーション、レイヤータイプ別配色 |
| 配色スキーム | ランダム/不一致 | 7 色のセマンティックシステム（青=サービス、緑=データベース、紫=セキュリティ…） |
| 接続線ルーティング規則 | 基本的 | アンカー割り当て、接続分散、コリドー迂回 |
| コンテナ/グループ | なし | Swimlane、Group、カスタムコンテナ + 親子ネスト |
| 埋め込みエクスポート | いいえ | はい — `--embed-diagram` でエクスポートファイルを編集可能に保持 |
| ブラウザフォールバック | いいえ | はい — CLI 利用不可時に diagrams.net URL を生成 |
| デスクトップ版を自動起動 | いいえ | はい — エクスポート後に `.drawio` ファイルを自動で開いて精修 |

## コアアドバンテージ

1. **セルフチェック + イテレーティブループ** — 純粋 SKILL.md スキームの中で唯一、出力を自動的に読み取り、問題を修正し、マルチラウンドの最適化をサポート
2. **6 種類の図表タイププリセット** — ERD、UML クラス図、シーケンス図、アーキテクチャ図、ML/深層学習、フローチャート — それぞれにプリセット形状、スタイル、レイアウト規範
3. **ML/DL モデル図** — テンソル形状アノテーション、レイヤータイプ別配色、エンコーダ/デコーダのスイムレーン — 学術論文用に専用設計
4. **マルチエージェント、ゼロ設定** — 6 プラットフォーム横断で動作、必要なのは `skills/drawio-skill/` ディレクトリと draw.io デスクトップ版のみ、MCP、Python、Node.js、ブラウザ不要
5. **プロフェッショナルグレードのレイアウト** — グリッド整列座標、複雑度別階層スペーシング、ルーティングコリドー、hub 中央配置戦略、アニメーション接続線
6. **ブラウザフォールバック** — デスクトップ CLI 利用不可時に diagrams.net URL を生成、エクスポート後にデスクトップ版を自動起動して編集
