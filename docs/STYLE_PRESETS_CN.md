# スタイルプリセット

[English](STYLE_PRESETS.md)

スタイルプリセットでビジュアル風格を取り込み再利用し、複数の図表で一貫性を保てます。プリセットを有効化すると、組み込みの配色、形状語彙、フォント、接続線のデフォルト値を置き換えます。

## 組み込みプリセット

| 名前 | 説明 |
|------|------|
| `default` | クリーンな青/緑/黄の配色、組み込み規範と一致 |
| `corporate` | 低彩度のプロフェッショナル配色、ビジネスプレゼンテーション向き |
| `handdrawn` | 手描き風ストローク、非公式またはホワイトボード式の図表向き |

## プリセットを図表に適用する

```
画一个微服务架构图，使用我的 "corporate" 样式
```

または、デフォルトスタイルを設定して、その後のすべての図表で自動的に使う：

```
把 "corporate" 设为我的默认样式
```

## ファイルからスタイルを学習する

任意の `.drawio` ファイルや画像を指し示す：

```
从 ~/diagrams/brand.drawio 学习我的样式，保存为 "mybrand"
从 ~/diagrams/screenshot.png 学习我的样式，保存为 "mybrand"
```

Skill が自動的に配色、形状、フォント、接続線スタイルを抽出し、サンプル図をレンダリングしてプレビューを提供、確認後にのみ `~/.drawio-skill/styles/mybrand.json` に保存します。

## プリセットの管理

| あなたの発話 | 何が起こるか |
|---|---|
| "列出我的样式" | すべてのユーザーおよび組み込みプリセットをテーブルで表示 |
| "显示我的 `<name>` 样式" | プリセット JSON をフォーマット出力 |
| "把 `<name>` 设为默认" | すべての図表のデフォルトアクティブプリセットに設定 |
| "取消默认" | デフォルトをクリア（組み込み規範に戻る） |
| "删除 `<name>`" | ユーザープリセットを削除（確認を求める） |
| "把 `<a>` 重命名为 `<b>`" | ユーザープリセットを名前変更 |
