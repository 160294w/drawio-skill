# スタイルプリセット

[English](STYLE_PRESETS.md)

スタイルプリセットを使うと、ビジュアルのスタイルを取り込んで再利用でき、複数の図表で見た目の一貫性を保てます。プリセットを有効にすると、組み込みの配色、形状の語彙、フォント、接続線のデフォルト値をすべてプリセットの値で置き換えます。

## 組み込みプリセット

| 名前 | 説明 |
|------|------|
| `default` | 組み込みの規約に沿った、すっきりとした青/緑/黄の配色 |
| `corporate` | 彩度を抑えたプロフェッショナルな配色。ビジネスプレゼンテーション向け |
| `handdrawn` | 手描き風のストローク。カジュアルな図表やホワイトボード風の図表向け |

## プリセットを図表に適用する

```
画一个微服务架构图，使用我的 "corporate" 样式
```

または、デフォルトスタイルを設定して、これ以降のすべての図表で自動的に使うこともできます：

```
把 "corporate" 设为我的默认样式
```

## ファイルからスタイルを学習する

任意の `.drawio` ファイルや画像をスキルに指定します：

```
从 ~/diagrams/brand.drawio 学习我的样式，保存为 "mybrand"
从 ~/diagrams/screenshot.png 学习我的样式，保存为 "mybrand"
```

Skill が配色、形状、フォント、接続線のスタイルを抽出し、サンプル図をレンダリングしてプレビューを表示します。確認後にはじめて `~/.drawio-skill/styles/mybrand.json` に保存されます。

## プリセットの管理

| 入力例 | 動作 |
|---|---|
| "列出我的样式" | ユーザー作成と組み込みのプリセットをすべて表で表示 |
| "显示我的 `<name>` 样式" | プリセット JSON を整形して出力 |
| "把 `<name>` 设为默认" | すべての図表で使われるデフォルトに設定 |
| "取消默认" | デフォルト指定を解除（組み込みの規約に戻る） |
| "删除 `<name>`" | ユーザープリセットを削除（確認あり） |
| "把 `<a>` 重命名为 `<b>`" | ユーザープリセットの名前を変更 |
